Vos agendas et carnets d'adresses ont été convertis au format de Radicale 3. Si certaines données ont dû être ajustées (collections renommées, nouveaux UID pour des doublons…), le journal de la mise à jour les liste ; elles sont aussi enregistrées dans `__DATA_DIR__/radicale1-backup/migration-report.txt`.

Une copie des données et de la configuration d'origine de Radicale 1.1 est conservée dans `__DATA_DIR__/radicale1-backup`. Une fois que vous avez vérifié que vos clients se synchronisent correctement, vous pouvez la supprimer : `sudo rm -r __DATA_DIR__/radicale1-backup`.
