This upgrade replaces Radicale 1.1 by Radicale 3, which stores calendars and address books in a different format.

**Before upgrading, keep your own copy of the data:** `sudo cp -a /var/www/__APP__/collections /root/radicale1-collections`. In it, each `.ics` file is a calendar and each `.vcf` file an address book, which any client can import.

- **The data is converted automatically.** The upgrade first copies it to `/home/yunohost.app/__APP__/radicale1-backup` (kept even if the app is removed), converts it and has Radicale 3 check every item before starting. If anything cannot be converted, the upgrade stops and explains where the data is.
- **Clients keep working with the same address**, the one ending with the path of the app (without `/infcloud`). They will download everything once again on their next synchronization.
- **The InfCloud web client is removed.** Radicale's own web interface, at the address of the app, can create, import and export calendars and address books. To view and edit events in a browser, the AgenDAV app can be installed and connected to Radicale.
- **Every YunoHost user keeps being able to log in**, as before. Access can now be restricted from the permission of the app. Each user only accesses their own calendars and address books: sharing rules added to `/etc/__APP__/rights` are not migrated.
